# Terreno skills

Agent skills for [Terreno](https://github.com/TerrenoLabs/terreno), shipped as one plugin:

| Plugin | What it is |
| --- | --- |
| `terreno` (Claude Code) / `terreno-planning` (Cursor, Codex) | Lifecycle (Grow → Pick ⇄ Roast → Brew → Taste), goal-driven scans (Aim → Sweep → Sift → Plot → Track), PRD, app-building, docs, deployment, and verification skills |

## Install

```bash
# Any agent, via skills.sh: opens a picker grouped by bundle
npx skills add TerrenoLabs/terreno-skills

# Claude Code
/plugin marketplace add TerrenoLabs/terreno-skills
/plugin install terreno@terreno-plugins

# Codex
codex plugin marketplace add TerrenoLabs/terreno-skills
```

See [plugins/README.md](plugins/README.md) for each stage's contract.

## Install only one part

Each bundle is one skill that carries its member skills as references, so one name
installs a whole part of Terreno:

```bash
npx skills add TerrenoLabs/terreno-skills --skill lifecycle
```

Other ways to take a slice:

```bash
# Several bundles at once
npx skills add TerrenoLabs/terreno-skills --skill lifecycle --skill app

# One skill on its own
npx skills add TerrenoLabs/terreno-skills --skill terreno-1-grow

# Claude Code: one bundle as a plugin
/plugin install terreno-lifecycle@terreno-plugins
```

In the picker, each bundle is a group: space on the group header toggles every skill in
it. A bundle and its member skills hold the same content, so install one or the other.

Bundles are defined in [`bundles.json`](bundles.json). After changing it, or any skill
under `skills/`, run `python3 .github/scripts/bundles.py`; CI fails when the generated
files are stale.

## Layout

- `plugins/terreno-planning`: Cursor/Codex plugin tree
- `plugins/terreno-claude`: Claude Code plugin tree (scan skills are named `scan-*`)
- `skills/`: flat installable copy for `npx skills add`, plus one generated folder per bundle
- `bundles.json`: bundle definitions; source for the bundle skills, picker groups, and `skills.sh.json` groupings
- `.claude-plugin/`, `.cursor-plugin/`, `.agents/plugins/`: marketplace manifests
